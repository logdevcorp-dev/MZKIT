## Програми з дисципліни «Основи програмування»

- `lab2_piecewise.cpp` — лабораторна №2, завдання 2. Обчислює кусково задану функцію для введеного x за допомогою консольного меню.
- `lab4_cosine_series.cpp` — лабораторна №4, завдання 1. Обчислює суму перших n членів тригонометричного ряду та виводить проміжні суми.
- `lab4_geometric_series.cpp` — лабораторна №4, завдання 2. Обчислює суму геометричного ряду трьома способами: циклами for, while і do-while.
